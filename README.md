# FITback

אפליקציה למדריכי כושר — שיעורים כמוצר סגור (black box), פיד גילוי, מטבע פנימי ומשוב חווייתי מלקוחות.

## תמיד פתוח בטלפון (אותו WiFi)

פעם אחת במחשב:
```bash
npm run always-on:install
```

יופיע חלון סיסמה של המק — כדי שהמחשב **יישאר דולק גם כשסוגרים את המסך**.

אחרי ההתקנה:
1. הכתובת נשמרת בקובץ **FITback-phone.txt** על שולחן העבודה — למשל `http://192.168.1.5:5199`
2. הטלפון והמחשב על **אותו WiFi**
3. פתחי את הכתובת ב-Safari → שתף → **הוסף למסך הבית**

האפליקציה רצה רק על המחשב (אין כתובת לאינטרנט). **אל תשימי אותו בתיק סגור** — הוא יכול להתחמם.

כדי לבטל:
```bash
npm run always-on:uninstall
```

## פתיחה בטלפון (ידנית)

```bash
npm run dev
```

בטרמינל תופיע כתובת כמו `http://192.168.1.5:5199`. הטלפון והמחשב חייבים להיות על אותו WiFi.

אם אין שורת Network:
```bash
ipconfig getifaddr en0
```
ואז פתחי `http://<IP>:5199` בטלפון.

## הרצה

```bash
cd FITback
npm install
npm run dev
```

פתחי בדפדפן: http://localhost:5199

> **שים לב:** הפורט 5199 שמור ל-FITback בלבד (לא 5173 — שם רצים פרויקטים אחרים).

## מסכים

| מסך | נתיב | תיאור |
|-----|------|--------|
| התחברות | `/` | Splash + כניסה |
| דשבורד | `/dashboard` | ארנק, ביצועים, תובנות AI |
| פיד | `/feed` | גילוי שיעורים ממדריכות אחרות |
| פרטי שיעור | `/lesson/:id` | רכישה / צפייה במבנה |
| ספרייה | `/library` | שיעורים שלי |
| יצירה | `/create` | תפריט בניית שיעור |
| בונה | `/builder` | מבנה שיעור + תרגילים |
| תרגילים | `/exercises` | בחירת תרגילים לשיעור |
| תרגיל חדש | `/exercises/new` | יצירת תרגיל מותאם |
| משוב לקוחה | `/feedback/:id` | דירוג חוויה |
| פרופיל | `/profile` | פרופיל מדריכה |
