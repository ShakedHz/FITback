# FITback

אפליקציה למדריכי כושר — שיעורים כמוצר סגור (black box), פיד גילוי, מטבע פנימי ומשוב חווייתי מלקוחות.

## פתיחה בטלפון

1. עצרי את השרת (Ctrl+C) והריצי מחדש:
   ```bash
   npm run dev
   ```
2. בטרמינל יופיע שורה **Network** — למשל `http://192.168.1.5:5199`
3. ודאי שהטלפון והמחשב **על אותו WiFi**
4. פתחי את הכתובת ב-Safari (אייפון) או Chrome (אנדרואיד)
5. **אייפון:** שתף → "הוסף למסך הבית" — האפליקציה תיפתח כמו אפליקציה native

אם אין שורת Network, מצאי את כתובת ה-IP של המחשב:
```bash
ipconfig getifaddr en0
```
ואז פתחי `http://<IP>:5199` בטלפון.

## הרצה

```bash
cd FITback
npm install
npm run dev
```

פתחי בדפדפן: http://localhost:5199

> **שים לב:** הפורט 5199 שמור ל-FITback בלבד (לא 5173 — שם רצים פרויקטים אחרים).

|-----|------|--------|
| התחברות | `/` | Splash + כניסה |
| דשבורד | `/dashboard` | ארנק, ביצועים, תובנות AI |
| פיד | `/feed` | גילוי שיעורים ממדריכות אחרות |
| פרטי שיעור | `/lesson/:id` | רכישה / צפייה במבנה |
| ספרייה | `/library` | שיעורים שלי / נרכשו |
| יצירה | `/create` | תפריט בניית שיעור |
| בונה | `/builder` | מבנה שיעור + תרגילים |
| תרגילים | `/exercises` | ספרייה עם סרטוני דמו + תצוגה מקדימה |

| משוב לקוחה | `/feedback/demo` | דירוג חוויה בלבד |
