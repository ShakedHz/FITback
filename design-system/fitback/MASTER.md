# FITback — Design System Master

White + ink purple. Instructor phone app. Hebrew-first.

Home is a **studio timetable**, not a dashboard of widgets. The next class is marked. Everything else stays quiet.

Default theme is **light**. Dark is an opt-in ink paper, not a second brand.

| Token | Light | Dark |
|------|-------|------|
| Paper | `#F7F7F9` | `#121018` |
| Card | `#FFFFFF` | `#1C1824` |
| Line | `#E6E4EC` | `#2E2A38` |
| Ink | `#18141F` | `#F3F1F7` |
| Purple | `#6D28D9` | `#6D28D9` |
| Gold (stars only) | `#D97706` | `#D97706` |

Display: Rubik on names/titles. Body: Heebo. Radius 12. No glow, no photo tiles, no raised FAB, no decorative rails.
